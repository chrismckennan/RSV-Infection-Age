# RSV-Infection-Age
R code to estimate parameters in a probability model that predicts age of first RSV infection from birth timing, demographics, and RSV surveillance data. A preprint can be found  [here][https://www.medrxiv.org/content/10.1101/2025.04.01.25325040v1].

# Running the code
The file SimulateAndAnalyze.Rmd contains all of the steps needed to run our code. Since the data used in our study contain birthdates that cannot be shared publicly, we have provided code to simulate birthdates and RSV infection ages. The file SimulateAndAnalyze.html provides example output after knitting SimulateAndAnalyze.Rmd in R-studio.
